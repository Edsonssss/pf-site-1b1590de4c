# ИИС (Т-Банк) — второй счёт

Секция «🏦 ИИС (Т-Банк) — второй счёт» на странице — **полноценная часть портфеля**,
а не справочный блок: те же колонки, что и в таблице «Акции» (цена, Δ за день,
рекомендация, цель, потенциал, диапазон, дивиденды/купоны, статус, дивдоход 12м),
свой фильтр по рекомендации и своя сортировка по клику на заголовок.

Стоимость ИИС входит в «Портфель всего», в доли (`shares_pct.iis`),
в «Итого вкл. заблокированные» и «Семейный итог», в дивидендную доходность
портфеля и в карточку «Рекомендации». Исключение — «Потенциал»: у облигаций
нет консенсус-целей, поэтому они в нём не участвуют.

## Где лежат данные

```json
"iis": {
  "name": "ИИС (Т-Банк)",
  "note": "облигации · учитывается в общих итогах",
  "positions": [
    {"n": 1, "ticker": "RU000A10C5L7", "name": "Селигдар 001Р-04", "qty": 30,
     "current_price": 1003.38, "prev_close": 1003.08, "prev_date": "2026-11-17",
     "day_change_pct": 0.03, "value": 30101.4,
     "recommendation": null, "target_price": null, "upside_pct": null,
     "range_min": null, "range_max": null, "n_forecasts": null,
     "dividend_next": 15.62, "dividend_date": "ожидается 14.12.2026 (покупка до 10.12.2026)",
     "dividend_status": "купон объявлен", "div_yield_12m_pct": 20.2,
     "instrument_type": "Bond", "isin": "RU000A10C5L7", "maturity": "2028-01-08",
     "note": "переведено с основного счёта 2026-11-17 · облигация, погаш. 08.01.2028 · …"}
  ]
}
```

Схема позиции = схема строки «Акций» + `isin`, `instrument_type`, `maturity`
(для облигаций). `ticker` может быть биржевым тикером (акции) или ISIN (облигации) —
конвейер сам находит бумагу на MOEX по первичному режиму торгов.

## Кто какие поля обновляет

| Поле | Кто обновляет |
|---|---|
| Цена, вчера, Δ за день, стоимость, доля | `auto_update.py` — MOEX ISS; облигация = % номинала + НКД (`ACCRUEDINT`) |
| Купоны облигаций: дивиденд ₽, отсечка, статус, дивдоход 12м | `auto_update.py` — календарь купонов MOEX (bondization); будущий купон попадает и в панель «Ближайшие дивиденды и купоны» |
| Дивиденды/дивдоход акций на ИИС | `auto_update.py` — из общего справочника `dividends_raw.json` (как у основного счёта) |
| Консенсус: рекомендация, цель, диапазон, потенциал | `fetch_forecasts.py` — Т-Банк; только акции, у облигаций «—» |
| Количество (`qty`), названия | вручную (edit.html сохраняет секцию iis без изменений) или по сверке с `tbank_iis.json` |
| Итоги: `iis_value`, `total_value`, `shares_pct.iis`, дивиденды 12м по обоим счетам, `recommendations` | `auto_update.py` / `fetch_forecasts.py` |

## Выгрузка и сверка с Т-Банком

`fetch_tbank_portfolio.py` теперь обслуживает **оба счёта**: после основного он
сам находит счёт типа `ACCOUNT_TYPE_TINKOFF_IIS` (или берёт `--iis <id>` /
секрет `TB_IIS_ACCOUNT`), сохраняет `tbank_iis.json` и сверяет количества
с `iis.positions` на сайте (по тикеру/ISIN, все типы кроме валюты).
Workflow `tbank_sync.yml` коммитит оба файла. Сверка — только отчёт:
количества на сайте вы правите сами (как и для основного счёта).

## Как добавить позицию ИИС вручную

Минимальный набор — `ticker`, `name`, `qty` (и `current_price` с `value` для
первого показа до ближайшего ночного обновления): остальное (цена, купоны,
дивиденды) подтянет `auto_update.py` на следующем запуске.

## Что важно знать

- «Дивиденды» на странице и в сводке — **гросс по обоим счетам**: дивиденды акций
  основного счёта + купоны облигаций ИИС (для облигации «дивдоход 12м» — это
  купонная доходность за 12 мес к текущей цене).
- На графике «Динамика остатков» есть серия «ИИС (Т-Банк)» — линия появится,
  как только в истории накопятся записи с полем `iis` (пишется ежедневно);
  линия «Итого портфель» включает ИИС сразу.
- Excel (`make_excel.py`) получает лист **«ИИС (второй счёт)»** с теми же 19
  колонками, что и лист портфеля (доля — внутри ИИС).
- `edit.html` («Правка позиций») редактирует основной счёт; секция `iis` при
  сохранении JSON проходит насквозь без изменений.
